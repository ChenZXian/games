Design

The game uses a recipe order loop. The player chooses an order, follows each cooking step, uses the correct kitchen tool, manages heat and patience, plates the finished dish, and receives score, stars, coins, and unlock feedback.

Expansion

Add ingredients in IngredientSystem.
Add recipes in RecipeManager.
Add tool matching rules in KitchenToolSystem.
Add score rules in ScoringSystem.
Add reward rules in RewardManager.

Run

Open this project in Android Studio and run the app module.
